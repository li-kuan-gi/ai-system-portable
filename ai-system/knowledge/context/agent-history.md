# Agent History

本檔存放 agent 可讀的歷史對話摘要、交接狀態與未完成脈絡。

portable package 中本檔應保持初始化狀態。導入到實際 workspace 後，才由 instance adapter 或 agent 依來源證據補上內容。

## 讀取時機

- 任務需要延續前次對話、尚未完成的決策、已承諾的下一步或使用者前次指示時，先讀本檔。
- 任務看起來與先前制度、知識或安全網討論有關，但目前對話沒有完整上下文時，先讀本檔。
- 若本檔沒有相關內容，不要猜測歷史脈絡。

## 寫入規則

- 優先寫摘要、決策、待辦與來源，不直接貼長篇 raw transcript。
- 每段歷史都應標明來源日期或來源位置。
- 不得寫入 secret、token、password、cookie、credential、完整 auth state 或私密 session dump。
- AI 服務的原始對話資料若保留在服務自己的 storage，只能在本檔記錄非敏感索引或摘要。
- 已過時或被新結論取代的內容，整理時應移除或標為已失效。
